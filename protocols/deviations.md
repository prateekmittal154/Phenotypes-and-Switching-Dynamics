# Deviations from the frozen Milestone 1 protocol

| ID | Change | When | Effect on gates |
|---|---|---|---|
| D1 | **S5 re-parametrised** after the quick run (R = 60). Clone weights changed (1, 30, 1000) → (1, 1000, 30), and the induction target moved from state 0 to the rarest primary state of clone 1. The original choice gave the induced clone a 1% metastatic share (τ_true = 0.009) and absorbed the induction inside the within-clone selection bound, so it could not test the clone bound. The protocol fixed only "clone weight ratio up to 1,000; within-clone ratio ≤ 5; 20% induction". | After the quick run, before the full run | None. S5 enters G5 via coverage only, and the coverage criterion is unchanged. |
| D2 | **The second "perturbation" family in E2** (Q = selected-and-perturbed P) is reported in addition to the frozen Dirichlet family. | Written before the quick run; τ_true columns added after it | **G3 is judged on the frozen family only**, as specified. The perturbation family is reported as a critical-review result. |
| D3 | **The single-metastasis founder-bottleneck analysis** (e6_single_met_neutral) extends the frozen multi-metastasis design to the plug-in/robust bound under neutral seeding. | Written before the quick run | None. It is part of Task 8, the critical review. |
| D4 | **The monotonicity check** now reports the largest violation instead of a boolean. | After the quick run | None. |

## Milestone 2
| ID | Change | When | Effect |
|---|---|---|---|
| D5 | **Technical control added** (`run_controls.py`): the within-clone shift recomputed for all held-out programmes and three QC covariates. | After H1 showed a within-clone reversal | Strengthens the analysis. It led to the within-clone shift being withdrawn as a biological claim. |
| D6 | **H2 permutation test.** The first pass reported a Spearman p-value over non-independent pairs, which is invalid. The pre-registered clone-stratified permutation test was then run and is the only one used. | After the first pass | The conclusion changes: mouse 2 is not significant under the valid test. |
| D7 | **M3 not fitted as a CTMC.** Differential growth and founder bottlenecks do not enter a likelihood that conditions on the tree. M3 is assessed by simulation instead. The pre-registration listed M3 among the models; this is a correction, not a relaxation. | Noted before fitting | None: M3 was never a confirmatory comparison. |
| D8 | **Plateau fit constrained to A ≥ 0, B ≥ 0** and reparameterised in lineage distance. The initial unconstrained fit returned values like A = −260, which are not variances. | After the E8 quick run, before the full runs | Fixes an estimator defect; the constraint follows from Proposition T2. |
| D9 | **Two-step estimator introduced** after the quick run showed that a flat curve is fit equally by a plateau and by a non-decaying memory term (Proposition T3). | After the E8 quick run | This is the main methodological addition of Milestone 2. |

## Milestone 3
| ID | Change | When | Effect |
|---|---|---|---|
| D10 | **Milestone 2 interpretation corrected.** The plateau B = Var_c(pi_c) was described as "heritable switching propensity". It is invariant to every switching rate and in fact measures clone-associated equilibrium **occupancy** (U1). The two "immunity" claims were also narrowed (U2, U3). | Start of Milestone 3, prompted by the brief | Substantive. The Milestone 2 plateau *estimates* stand; their interpretation does not. The Simeonov composition finding is untouched, as it never used the plateau. |
| D11 | **Per-clone estimator added** (`src/lineage_inference/perclone.py`): (pi_c, k_c) by ML with profile intervals, plus noise-corrected variance components V_pi and V_logk, LRTs and a `k_at_bound` flag. Supersedes the pooled two-step estimator for any question about dynamics. | Milestone 3 | Main methodological addition. |
| D12 | **LRT optimiser iterations capped** (400 -> 60 per parameter) after the first E10 launch was projected to take several hours per design cell. | After the first E10 launch, before any E10 result was read | Makes the LRT p-values slightly conservative. The variance components, which carry the conclusions, are unaffected. |
| D13 | **Quinn (GSE161363) analysed for tree geometry only.** The small lineage and metadata files were downloaded; the expression matrices (62-286 MB each) were not, so no cell states were defined for that system. The cross-technology comparison is therefore of MRCA-depth spectra and identifiability windows, not of biology. | Milestone 3 | Narrows the independent-system claim to what the downloaded data support. |
| D14 | **Park et al. DNA Typewriter not analysed.** Availability was not established in Milestone 1 and was not revisited; no data were located in this milestone. | Milestone 3 | The time-resolved question remains open and is listed as a next experiment. |
| D15 | **Profile intervals widened to contain the MLE.** The profile likelihood is evaluated on a grid while the point estimate is refined off-grid, so a grid interval could exclude its own MLE (e.g. mouse 1 clone 3). Intervals are now reported as the union of the grid interval and the point estimate. | After the real-data run, applied in the figure and fixed at source for future runs | Cosmetic: it widens a few intervals slightly and changes no conclusion. The tables carry the unwidened values. |
| D16 | **Full E10 grid stopped after the OCC arm.** The full 4-mechanism x 3-clone-count grid was projected at several more hours. `run_e10_focus.py` answers the same question at 20 clones with 10 replicates and parallel execution (237 s), and E11 already varies clone count from 5 to 40, so the scaling information is covered. The partial E10 log is kept; its tables were not produced. | After e10_focus completed | None on any conclusion. The identifiability claims rest on e10_focus and e11. |

## Milestone 4
| ID | Change | When | Effect |
|---|---|---|---|
| D17 | **Milestone 3 window criterion corrected.** M3 reported recorder windows of 0.09-0.24 decades using the ad-hoc range 1/(2L_max)..1/(2L_min). On a Fisher-information criterion the same recorders cover 1.1-1.2 decades. Pointers added to the M3 reports; the qualitative conclusion is unchanged. | M4, after the Fisher audit | Quantitative correction to an M3 headline. |
| D18 | **kL\* restated.** M3 gave kL\* ~ 0.405 from two occupancy values. Over pi in [0.1, 0.7] the optimum is 0.39-0.49 (mean 0.43), and estimating pi jointly costs <=6% of the information. The optimum is also flat: >=50% of peak information over a ten-fold band of kL. | M4 | Corrects a claim of constancy that was based on too narrow a sweep. |
| D19 | **Quinn state definition changed before any analysis.** The unsupervised PC1 axis correlated with mitochondrial fraction (-0.67 to +0.60 across mice) even after excluding mitochondrial and ribosomal genes, so it is substantially a cell-quality axis. Cell-cycle score (fixed external gene set) is used as the primary state and PC1 is reported only as a sensitivity analysis. | Before running the Quinn occupancy analysis | Avoids building conclusions on a technical axis. |
| D20 | **Quinn trees bounded.** Only the authors' primary `hybrid_priors.alleleThresh` reconstruction is used (three reconstructions exist per lineage group and using all three triple-counted cells); trees above 1,500 matched cells are skipped and at most 30 trees per mouse are fitted, to bound the likelihood-ratio optimisation. | During the Quinn run | Reduces the analysed cell count; documented in the dataset report. |
| D21 | **E15 design objective reformulated.** The first version scored information about the grand occupancy, which is fixed by the cell budget and cannot discriminate designs, and modelled staggered recording in a way that could only lose resolution. Replaced by a recorder-capacity formulation with an occupancy-variance objective (`run_e15b.py`). Both scripts are kept. | After inspecting the first E15 output | The reformulated version supports the reported design law; the first is superseded. |

## Milestone 5
| ID | Change | When | Effect |
|---|---|---|---|
| D22 | **E17 pilot settings changed before the full run.** The pilot at k = 0.1 with 48 leaves gave an estimator so unstable that even the true-tree fit was biased 2.7x upward. k = 0.1 was dropped (keeping 0.3, 1.0, 2.0), the sample raised to 96 leaves, and the headline statistic changed to paired within-replicate log-ratios, which cancel replicate-level noise. | After the pilot, before the full run | The absolute biases are not comparable with the pilot; the paired design carries the conclusions. |
| D23 | **Robinson-Foulds comparison was wrong in the first full run** and reported 0.0 recovery everywhere. T1 leaves were indexed by position in the induced subtree while T3 leaves were indexed by sample position, so no clade could ever match. Fixed by mapping both to a common label space; the experiment was rerun in full. The bugged log is kept as `e17_buggedRF.log`. | After the first full run | Topology-recovery numbers in the first run were meaningless and are not used. All other E17 results were unaffected and reproduced closely on the rerun. |
| D24 | **Joint barcode-likelihood inference (strategy C) was not implemented.** Proposition V1 bounds it above by the information in the sampled genealogy, and E17 shows the informative pairs are absent from the sample, so its ceiling is already measured. | Scoping decision, documented in `milestone5_uncertainty_calibration.md` | A real gap in the method comparison, stated rather than worked around. |
| D25 | **Real-data reconstruction ensemble covers one animal.** All three reconstructions are deposited only for the Quinn 5k mouse; the other three mice have the hybrid tree only. For Simeonov, three reconstructions were built from the authors' allele records instead. | On inspecting the deposit | Narrows the ensemble claim to what the data support. |
| D26 | **Interval coverage under reconstruction error was not measured.** E17 reports bias and spread of point estimates only. | Milestone 5 | Listed as the first next computation. |

## Milestone 6
| ID | Change | When | Effect |
|---|---|---|---|
| D27 | **A proposed branch-time correction was tested and rejected.** Rescaling every edge by a single factor c = D/h worsened interval coverage (0.494 -> 0.362) and bias (+1.33 -> +1.98), because it equalises only the deepest root-to-leaf path. It is retained in the results as variant V4a because the failure is informative; the valid construction is ultrametric. | During E20 | Strengthens the branch-time analysis; no conclusion rests on the failed variant. |
| D28 | **E22 bootstrap made tractable.** The first version recomputed profile intervals inside the bootstrap loop that it never used, projecting to hours per dataset. A point-estimate-only mode was added to `fit_clone`, grids coarsened for the inner loop, and caps tightened to <=12 trees and <=400 cells per tree, with B = 120. | Before any E22 result was read | V_pi values in Milestone 6 are computed on a subset of trees and differ numerically from Milestone 4; significance conclusions are unaffected. The stricter caps also drop the Quinn 30k animal, so the eligible-animal count for this analysis is **5, not 6**. |
| D29 | **E21 run at 5 replicates, not 30.** The quick configuration took 3.2 hours; the planned 30-replicate version would take ~19 hours and was not run. | After the quick run | The close-relative-pair result is precise; the interval-coverage ordering is underpowered and is labelled suggestive rather than established. |
