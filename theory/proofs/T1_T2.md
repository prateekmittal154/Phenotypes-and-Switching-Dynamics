# Proofs of T1–T5

Notation as in `../branching_model.md`. Within clone c write π = π_c, q = 1 − π, k = k_c.

## Lemma T1
The two-state generator is Q = [[−a, a], [b, −b]] with π = a/(a + b) and k = a + b. Its exponential is

  P(L) = e^{QL} = [[q + πE, π(1 − E)], [q(1 − E), π + qE]],  E = e^{−kL},

which is checked by noting that P(0) = I, that each row sums to 1, and that dP/dL = QP.

Let Z be the MRCA state, drawn from the stationary law P(Z = 1) = π. Given Z, the two descendant paths are
conditionally independent, each of length L, so

  E[X_i X_j] = Σ_z P(Z = z) P(L)[z, 1]².

With P(L)[0, 1] = π(1 − E) and P(L)[1, 1] = π + qE,

  E[X_i X_j] = q·π²(1 − E)² + π·(π + qE)².

Expand the bracket:
  qπ(1 − E)² = qπ − 2qπE + qπE²,
  (π + qE)²  = π² + 2πqE + q²E².
Their sum is qπ + π² + E²(qπ + q²) = qπ + π² + qE²(π + q) = qπ + π² + qE².
Since qπ + π² = π(q + π) = π,

  E[X_i X_j] = π(π + qE²) = π² + πq E².

As E[X_i] = E[X_j] = π (stationarity),

  Cov(X_i, X_j | c, L) = πq E² = π_c(1 − π_c) e^{−2 k_c L}.  ∎

The exponent is 2kL because the two leaves are separated by **two** branches of length L.

## Proposition T2
Let the clone label c be random with P(c) = w_c, and let the pair be at lineage distance L within its clone. By the
law of total covariance,

  Cov(X_i, X_j) = E_c[Cov(X_i, X_j | c)] + Cov_c(E[X_i | c], E[X_j | c]).

The first term is E_c[π_c(1 − π_c) e^{−2 k_c L}] by Lemma T1. For the second, E[X_i | c] = E[X_j | c] = π_c, so it
is Var_c(π_c). Hence

  Cov(X_i, X_j) = A(L) + B,  A(L) = E_c[π_c(1 − π_c) e^{−2 k_c L}],  B = Var_c(π_c).  ∎

Note where each assumption is used: stationarity within clone gives E[X | c] = π_c (without it the second term is
the covariance of the two leaves' conditional means, which still equals Var_c of the clone mean when both leaves
are in the same clone); conditional independence given the MRCA state gives the product form in Lemma T1.

**Corollary T2.1.** Under Mechanism C the rates are a_c g_o and b_c ℓ_o, so the stationary fraction in compartment
o is π_{c,o} = a_c g_o / (a_c g_o + b_c ℓ_o). If induction is common to clones in the sense that g_o / ℓ_o does not
depend on c, then the logit of π_{c,o} is logit(π_c) + log(g_o / ℓ_o): a pure compartment shift. Restricting the
analysis to one compartment and centring at that compartment's mean leaves Var_c(π_{c,o}), which is zero whenever
Var_c(π_c) is zero. Induction alone therefore contributes nothing to B. ∎

(If induction instead *interacts* with clone, i.e. g_o/ℓ_o varies by clone, then it does contribute to B. That is a
genuine clone-by-environment interaction and is reported as such; it is not separable from B within one
compartment, and requires comparing B across compartments.)

**Corollary T2.2.** Under Mechanism A all clones share π, so B = Var_c(π_c) = 0, and k → 0 makes
A(L) → E[π(1 − π)], a constant. All the covariance sits in A. ∎

## Proposition T3
Write the observed curve as a function of MRCA depth h, with L a decreasing function of h and
C(h) = A e^{−2k L(h)} + B when k_c ≡ k.

*If k = 0:* e^{−2kL} = 1 for all h, so C(h) = A + B identically. Any (A', B') with A' + B' = A + B gives exactly the
same curve, so A and B are not separately identified; only the sum is. Taking A' = 0, B' = A + B realises the fitted
curve with a pure plateau, and A' = A + B, B' = 0 realises it with pure state memory. These correspond to Mechanism
B and to Mechanism A with frozen state respectively, so the two mechanisms are observationally equivalent. ∎

*If k > 0 and A > 0:* the map (A, k, B) ↦ C(·) is injective on any set of three or more distinct distances, because
A e^{−2kL} + B determines B as lim_{L→∞}, then A and k from two further points of a strictly monotone exponential.
Identification therefore holds exactly when the observed range of L is wide enough for the exponential to vary
appreciably, which is the stated condition 2k(L_max − L_min) bounded away from 0. ∎

*Two-step estimator.* Centring at the clone mean replaces X by X − π_c, whose conditional mean is 0, so the second
term of the total-covariance identity vanishes and the clone-centred curve equals A(L) plus the finite-clone
centring bias −Var(X | c)/(n_c − 1), which is constant in h. Fitting A e^{−2kL} + d to that curve therefore
identifies k without reference to B. With k fixed, C(h) = A e^{−2kL(h)} + B is linear in (A, B) and both are
non-negative, so a non-negative least-squares fit is exact and unique whenever the design vector e^{−2kL} is not
constant. ∎

## Proposition T4
Condition on clone c in compartment o, founded by N cells whose states at founding are i.i.d. Bernoulli(π_c) and
whose descendant counts are Z₁..Z_N. If switching after founding is negligible over the observation window, the
realised high-state fraction is F = Σ_i Z_i 1{S_i = 1} / Σ_i Z_i, so

  Var(F | Z) = π_c(1 − π_c) Σ Z_i² / (Σ Z_i)² = π_c(1 − π_c) / N_eff,  N_eff = (Σ Z_i)² / Σ Z_i².

If the tree does not resolve founder identity, pairs descending from different founders are not recognised as
distant, and the empirical plateau estimates Var_c(F) rather than Var_c(π_c). Taking expectations over clones,

  E[B̂] ≈ Var_c(π_c) + E_c[π_c(1 − π_c) / N_eff,c].

The inflation vanishes as N_eff → ∞ and is largest for oligoclonal metastases. ∎

## Proposition T5 (measurement value)
Each claim follows from T2–T4.
1. *Clone labels only.* The observable is Var_c(F_c), which by T4 equals Var_c(π_c) + E[π(1−π)/N_eff] and, when
   switching is slow, also absorbs state memory. It is an upper bound on B, not an estimate of it.
2. *Clone labels plus a resolved tree.* A and B are separated under T3.
3. *Compartment labels.* By T2.1 these identify induction only as a compartment main effect. A per-clone induction
   effect requires the same clones to be observed in two compartments, and is then a clone-by-compartment
   interaction.
4. *A second time point.* π_c and k_c are identified from one harvest by T2–T3, but a_c and b_c separately, and any
   growth rate, are not: the tree is conditioned on, so division and death do not enter the fixed-tree likelihood.
   Absolute rates need a second time point or a known clock. ∎
