# Proofs of P1–P4

Notation as in `../definitions.md`. All sums run over the finite X.

## P1 (observational equivalence)
**Pure selection.** Take w = Q/P on supp P (positive on supp Q = supp P) and K = I. Then π = PQ/P / ⟨P, Q/P⟩ = Q,
because ⟨P, Q/P⟩ = Σ Q = 1. So πK = Q, and τ = 0.

**Pure induction.** Take w ≡ 1 and K(y | x) = Q(y). Then π = P and πK = Q, with τ = Σ_x P(x)(1 − Q(x)) = 1 − ⟨P, Q⟩.
This construction does not use supp Q ⊆ supp P, so pure induction fits every (P, Q).

Both mechanisms generate the same observable pair (P, Q). Any estimator that is a function of (P, Q), or of samples from
them, has the same output distribution under both. ∎

## Lemma A (maximal coupling; Lindvall 1992, Thm I.5.2)
For π, Q ∈ Δ(X), min over couplings γ of γ(X ≠ Y) = TV(π, Q). The minimiser puts mass min(π(x), Q(x)) on the diagonal.

## Lemma B (box projection)
Let 0 ≤ l ≤ u componentwise, with Σl ≤ 1 ≤ Σu, and let Q ∈ Δ. Then

  min{ TV(π, Q) : l ≤ π ≤ u, Σπ = 1 } = max(A, B),  with A = Σ (Q − u)₊ and B = Σ (l − Q)₊.

**Proof.**
- *Lower bound.* For feasible π, TV(π, Q) = Σ(Q − π)₊ ≥ Σ(Q − u)₊ = A, because π ≤ u. Also
  TV(π, Q) = Σ(π − Q)₊ ≥ Σ(l − Q)₊ = B. These two expressions for TV are equal because Σπ = ΣQ = 1.
- *Attainment.* Let π⁰ = clip(Q, l, u). Then Σπ⁰ = 1 − A + B.
- *Case A ≥ B.* Add Δ = A − B. The room is Σ(u − π⁰) = Σu − 1 + A − B ≥ Δ. Add only at coordinates with π⁰ < u. There
  Q < u, so π⁰ = max(Q, l) ≥ Q, and the addition leaves (Q − π)₊ = 0 at those coordinates. Coordinates with Q > u are
  untouched and contribute A. Hence Σ(Q − π)₊ = A = TV.
- *Case B > A.* Remove B − A from coordinates with π⁰ > l, where π⁰ = min(Q, u) ≤ Q. The room is
  Σ(π⁰ − l) ≥ B − A. Then Σ(π − Q)₊ = B. ∎

## P2 (sharp lower bound)
**Step 1: description of the selected laws.**

  Π_Λ = { π = P w / ⟨P, w⟩ : w > 0, max w / min w ≤ Λ on supp P }.

Write r = w / ⟨P, w⟩ and m = min r. Then π = P r, ⟨P, r⟩ = 1 and r ∈ [m, Λm]. Conversely, any such r arises from
w = r. Hence

  Π_Λ = ⋃_{m > 0} { π : mP ≤ π ≤ ΛmP, Σπ = 1 }.

The set for a given m is non-empty iff m ≤ 1 ≤ Λm, i.e. m ∈ [1/Λ, 1].

**Step 2: reduction to the selected law.**

  τ_min(Λ) = inf_{π ∈ Π_Λ} inf_{K : πK = Q} Σ_x π(x)(1 − K(x, x)).

The inner infimum is over couplings of (π, Q). By Lemma A it equals TV(π, Q).

**Step 3: apply Lemma B.** For each m, Lemma B with l = mP and u = ΛmP gives

  min_π TV = max(A(m), B(m)),  with A(m) = Σ(Q − ΛmP)₊ and B(m) = Σ(mP − Q)₊.

**Step 4: the outer minimisation.**
- A is continuous and non-increasing in m. B is continuous and non-decreasing.
- Hence max(A, B) is quasi-convex on the compact interval [1/Λ, 1].
- Its minimum is attained: at the crossing A = B if one exists, and otherwise at the endpoint where the larger function
  is smaller.
- Bisection on A − B, which is monotone, finds it.

**Identification in hockey-stick form.**
- A(m) = E_{Λm}(Q ‖ P).
- B(m) = Σ(mP − Q)₊ = m Σ(P − Q/m)₊ = m E_{1/m}(P ‖ Q).

**Sharpness.** The minimiser (m*, π*, γ*) defines a feasible mechanism: w = π*/P, which is positive on supp P because
π* ≥ m*P > 0, and K(y | x) = γ*(x, y)/π*(x). Its τ equals τ_min(Λ).

**Interval.** The set of feasible (π, m, γ) is a polytope. It is cut out by linear constraints, since mP ≤ π ≤ ΛmP is
linear in (π, m). It maps bijectively onto the feasible mechanisms, and τ is linear on it. The image of a compact convex
set under a linear functional is a closed interval, so T(Λ) = [τ_min(Λ), τ_max(Λ)].

**Numerical check.** E1 compares the closed form with an LP that uses neither lemma (`src/bounds/core.py::tau_min_lp`).
∎

## P3 (limits)
- **Λ = 1.** This forces m = 1 and π = P, so τ_min = max(Σ(Q − P)₊, Σ(P − Q)₊) = TV(P, Q).
- **Monotonicity.** Π_Λ grows with Λ.
- **Λ → ∞.** Take m = 1/√Λ. Then A(m) → Q(X \ supp P) = SM(P, Q) and B(m) → 0. SM is also always a lower bound, because
  π vanishes off supp P.
- **When τ_min(Λ) = 0.** τ_min(Λ) = 0 iff Q ∈ Π_Λ. This requires supp Q = supp P, because π > 0 on supp P, and the
  ratio Q/P must have spread ≤ Λ.
- **Upper end.** The pure-induction mechanism of P1 has w ≡ 1 ∈ M(Λ) for every Λ, so τ_max(Λ) ≥ 1 − ⟨P, Q⟩. ∎

## P4 (asymmetry)
- *Induction cannot be excluded.* By P1, pure induction is always feasible.
- *Pure selection can be excluded only if Λ < Λ\*.* τ = 0 is feasible iff Q ∈ Π_Λ (P3), i.e. iff Λ ≥ Λ\* :=
  max(Q/P) / min(Q/P), with Λ\* = ∞ if the supports differ.
- Pure selection is therefore excluded iff Λ < Λ\*. This is a statement about the *assumption* Λ, which (P, Q) cannot
  check: every Λ ≥ 1 is compatible with some mechanism that reproduces (P, Q). ∎
