# Counterexamples C6–C8 (Milestone 2)

## C6: clone labels alone cannot establish heritable propensity
Three clones, one compartment, states 0/1. Suppose every clone has the same propensity π = 0.5 but the state is
frozen (k = 0), and each clone descends from a founder population of N_eff = 4 cells.

By Proposition T4 the realised clone fractions then have variance π(1 − π)/N_eff = 0.0625, so an analyst who
measures only the spread of clone-level state fractions sees Var_c(F_c) ≈ 0.0625 and concludes that clones differ
heritably in propensity. The truth is Var_c(π_c) = 0.

**Realised numerically.** In E9 the stable-state scenario has true B = 0, yet the naive statistic
Var_c(empirical clone fraction) is **0.028** in the primary tumour. The decomposition returns **B̂ = 0 with a
bootstrap CI of [0, 0]** in every replicate. The founder-bottleneck scenario behaves the same way (naive 0.0029,
B̂ = 0). This is the practical content of T4: the statistic everyone computes first is an upper bound on B, not an
estimate of it.

## C7: frozen heritable state and heritable propensity give the same covariance curve
Let the observed MRCA depths h = 0..6 correspond to lineage distances L = 3.5, 3.0, 2.5, 2.0, 1.5, 1.0, 0.5.

| Mechanism | Parameters | C(h) over the observed range |
|---|---|---|
| **B, heritable propensity** | A = 0, k = 5, B = 0.25 | 0.2500 at every depth |
| **A, frozen state** | A = 0.25, k = 0.01, B = 0 | 0.2331 … 0.2475 |

The two curves differ by at most **0.017** across the whole observed range, and at k = 0 exactly they coincide
identically (Proposition T3). One mechanism has all of its covariance in heritable propensity, the other none.

Given the ideal clone-centred curve, the two-step estimator recovers frac_plateau = 1.00 for the first and 0.485
for the second, so the separation is possible **only** because the clone-centred curve pins down k. Where the data
cannot resolve k, the split is not identified at all.

**Realised in the real data.** In the Simeonov re-analysis the step-1 decay rate hit its lower bound in 7 of the
8 mouse-by-site combinations, and the plateau fraction then had a bootstrap CI of [0, 1] — completely
uninformative. Only mouse 2's primary tumour resolved the decay (k = 0.33) and returned a bounded interval.

## C8: a model-selection win for clone-specific propensity is not evidence of propensity
On the real trees, a model with clone-specific stationary fractions (M1) beats a single-state model (M0) by
ΔAIC = 250 in mouse 1 and 440 in mouse 2, and predicts a held-out metastatic site substantially better. It is
tempting to read this as proof of Mechanism B.

It is not. M1's clone-specific π_c is estimated from each clone's state composition, which by C6 and C7 contains
heritable propensity, frozen state memory and founder sampling together. Under the frozen-state mechanism of C7,
the same comparison would also select M1 decisively, because clones genuinely differ in composition — just not
because they differ in *propensity*.

The decomposition is the stricter test, and on the same data it supports Mechanism B in **one** of eight
mouse-by-site combinations. Both results are reported.
